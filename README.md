# iPhone Sales Dashboard

An interactive Streamlit dashboard for analyzing iPhone sales trends, performance metrics, and business insights.

## Features
- 📊 Real-time KPI metrics (revenue, units sold, average price)
- 📈 Monthly revenue and sales trends
- 🎯 Performance analysis by iPhone model and country
- 🌍 Market share visualization
- 📉 Variance analysis for market volatility
- 💡 Business insights and recommendations
- 🔍 Interactive filters for deep-dive analysis

## Installation

```bash
pip install -r requirements.txt
```

## Running Locally

```bash
streamlit run dashboard.py
```

The dashboard will open at `http://localhost:8501`

## Data Source
The dashboard uses iPhone sales data from `iphone_sales_dataset.csv`

## Dashboard Sections
1. **KPIs** - Key performance indicators overview
2. **Trends** - Revenue and unit sales trends
3. **Performance** - Category-based analysis
4. **Market Analysis** - Cross-tabular heatmap
5. **Variance Analysis** - Market volatility metrics
6. **Market Share** - Revenue distribution
7. **Business Insights** - Recommendations for growth

## Deployment
Deploy to Streamlit Cloud for free at https://streamlit.io/cloud
